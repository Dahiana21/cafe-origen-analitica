## Análisis de ventas

## ¿Qué es este proyecto?

Café  Origen es una tostadora de café de especialidad de Medellín que vende en su tienda fisica, en ferias y mediante pedidos en linea a distintas ciudades de Colombia.

Como desarrolladora junior de Nodo Digital, estoy construyendo la lógica de un motor de analítica para ayudar a Café Origen a responder preguntas sobre sus ventas.

## ¿Cómo ejecutar el proyecto?

1. Instala Node.js
2. Abre una terminal en la carpeta del proyecto
3. Ejecuta el archivo de reportes: node .\src\reporte.js

## ¿Qué preguntas responde?

## Preguntas sobre ventas
- ¿Cuánto dinero generó una venta individual.
- ¿Cuánto dinero se vendió en total.
- ¿Cuántas unidades se vendieron en total?.
- ¿Cuál fue la venta de mayor valor?.
- ¿Cuál fue el valor promedio de las ventas válidad?
- ¿Cuántos registros tienen una cantidad mayor que cero?
- ¿Cuántas unidades contiene una venta individual?

## Preguntas para comparar
- ¿Cuánto dinero se vendió en una ciudad especifica?
- ¿Cuánto dinero se vendio en cada ciudad?
- ¿Cuántas unidades se vendieron de cada producto?
- ¿Qué productos generaron más dinero? Devuelve el Top 3

## Preguntas de busqueda
- ¿Qué ventas corresponden a una fecha?
- ¿Cómo mostrar un número con formato de pesos colombianos?
- Se crearon funciones que ayudan a normalizar textos para compararlos y agruparlos
